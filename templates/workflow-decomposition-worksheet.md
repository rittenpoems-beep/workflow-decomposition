# 工作流拆解工作表

> 用法：复制下面「空白模板」到你的项目文档里，先填完第 1–4 节，再让 AI 开始执行。任何阶段没有验收标准，就不进入下一阶段。

## 示例：一个雨夜便利店的三维场景

### 0. 项目摘要

| 项 | 内容 |
|---|---|
| 项目 | 雨夜街角便利店三维场景 |
| 一句话目标 | 做一个能在浏览器里实时浏览、具有雨夜氛围的便利店街角 |
| 受众 / 场景 | 个人站「立体附录」，访客点击即可打开 |
| 时间 / 成本 | 2 天；单机 RTX 4060 / Intel UHD 验证 |
| 最终交付物 | 单文件 HTML（离线版）+ 源码 + 截图 + 验证记录 |

### 1. 交付物定义

- **形态**：网页，不是图片、不是 `.blend`
- **运行方式**：浏览器打开，可旋转、缩放、平移
- **性能预算**：1440×1080 下 ≥ 30 fps；离线版零外部请求
- **视觉标准**：风格化三渲二；雨夜、暖色店内光、湿地反射；构图完整显示底座
- **不交付**：影视级可编辑资产、分层渲染、动画镜头
- **什么算完成**：能打开、能交互、无控制台错误、帧率达标、截图通过自检

### 2. 参照与标准

| 参照 | 看什么 | 量化 / 可观察标准 |
|---|---|---|
| 雨夜街景参考图 | 冷暖对比、湿地反射、招牌光 | 冷蓝环境 + 暖色店内光，地面有可见反射 |
| 便利店参考 | 货架、饮料柜、收银台、关东煮 | 主要陈列可辨认 |
| 实时场景性能 | 帧率、绘制调用 | ≥ 30 fps；draw calls 控制在数百 |
| 交互 | 鼠标 / 触屏 | 旋转、缩放、平移均可用 |

### 3. 阶段拆解

| 阶段 | 输入 | 输出 | AI 做什么 | 人做什么 | 验收标准 | 常见失败 |
|---|---|---|---|---|---|---|
| 1. 定义 | 用途、受众 | 交付物与约束 | 提问、整理 | 拍板「网页实时」 | 一句话说清交付物 | 直接让 AI 生成 |
| 2. 参考 | 参考图、同类场景 | 氛围与构图标准 | 搜索、拆解 | 选参考、定风格 | 至少 2 张同类型参照 | 凭感觉说「电影感」 |
| 3. 资产拆解 | 参考图 | 场景清单 | 列建筑、道具、灯光 | 定 hero 元素 | 清单覆盖主要可见物 | 一次性生成整场景 |
| 4. Blockout | 清单 | 体块、机位 | 搭几何、摆相机 | 校构图与比例 | 白模构图成立 | 先做细节后改机位 |
| 5. 材质 / 灯光 | 白模 | 材质、布光 | 建材质、布灯 | 对照参考 | 冷暖关系与反射成立 | 材质好看但光不对 |
| 6. 动画 / 交互 | 场景 | 门、雨、涟漪 | 写动画、交互 | 检查手感 | 门循环、雨持续、交互可用 | 只做静态画面 |
| 7. 性能 | 场景 | 帧率报告 | 合并几何、降采样 | 定预算 | 1440×1080 ≥ 30 fps | 只看截图不看帧率 |
| 8. 交付 | 全部 | HTML + 源码 + 记录 | 打包、写说明 | 最终验收 | 离线可开、零请求、无报错 | 只交截图 |

### 4. 路线比较

| 路线 | 交付物 | 成本 | 风险 | 是否匹配 |
|---|---|---|---|---|
| Three.js 单文件 | 网页实时场景 | 低 | CDN 依赖、性能上限 | ✓ 匹配 |
| Blender + Cycles | 可编辑资产、离线静帧 | 高 | 无实时交互、交付重 | ✗ 不匹配当前目标 |
| 视频渲染 | MP4 | 中 | 不可交互 | ✗ 不匹配 |

**选择**：Three.js。**迁移成本**：如果之后要影视资产，需要重新建模，不能从网页场景直接转换。

### 5. 验收闸门

| 闸门 | 检查 | 结果 |
|---|---|---|
| 01 能运行 | 页面打开、无报错 | ✓ |
| 02 符合规格 | 1440×1080、≥30 fps、离线零请求 | ✓ |
| 03 符合参照 | 雨夜氛围、构图、冷暖对比 | ✓（范围限定为风格化实时） |
| 04 愿意签字 | 愿意作为个人站附录发布 | ✓ |

### 6. 不做什么

- 不做写实影视级资产；
- 不做可编辑 `.blend` 交付；
- 不做动画镜头；
- 不引入外部模型与贴图（保持单文件）。

### 7. 停止条件

- 1440×1080 连续两次优化后仍低于 30 fps；
- 离线版出现外部请求且无法定位；
- 视觉与参考差距无法通过材质/灯光调整缩小。

### 8. 交付清单

- [x] 单文件 HTML
- [x] 可编辑源码
- [x] 离线验证记录
- [x] 截图 3 张
- [x] 打开方式与已知问题

### 9. 复盘

- 路线选择正确，因为交付物在开工前就限定为「网页实时」；
- 最大的返工来自性能优化，而不是建模；
- 如果目标是影视资产，这条路线从第一天就是错的。
